# Calculator 🧮

A simple calculator built with **HTML, CSS, and Vanilla JavaScript**.

## About The Project

This project is a simple calculator created to practice core JavaScript concepts and understand how real user interactions work in the browser.

The main goal of building this project was to learn how to:

* Work with the DOM
* Handle button click events
* Store and manage user input
* Detect mathematical operators
* Separate numbers from operators
* Perform basic calculations using JavaScript logic

## Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)

## How It Works

The calculator stores the user's input as a string.

Example:

```
12+5
```

When the user presses the equal button, the program:

1. Finds the mathematical operator
2. Separates the numbers before and after the operator
3. Converts the values into numbers
4. Performs the calculation
5. Displays the result

## Purpose

This project was created as a learning project to improve JavaScript fundamentals and understand the logic behind building interactive web applications.
